# 안녕하세요, 김관영입니다 👋

사용자 입력 → 서버 데이터 → 화면 상태로 이어지는 흐름을 만드는 신입 개발자입니다.
React/TypeScript/Vite로 화면을 만들고, Spring Boot/MySQL로 API를 연동하는 작업을 주로 해왔습니다.
